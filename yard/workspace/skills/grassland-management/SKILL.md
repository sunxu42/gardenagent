# 草地管理规则

## 概述

本文档定义了自动化庭院系统中管理草地的规则和指南。这些规则根据草高、土壤湿度、天气条件和系统状态来决定何时割草、灌溉和维护草坪。

## 核心规则

### 割草规则

1. **高度阈值**: 
   - 如果草高小于7cm，不需要割草
   - 如果草高大于或等于7cm，应该考虑割草

2. **天气限制**:
   - 恶劣天气（下雨、强风）时不要割草
   - 等待天气条件改善后再割草

3. **土壤湿度限制**:
   - 土壤湿度过高时不要割草
   - 高土壤湿度可能损坏草坪并造成泥泞条件

4. **割草机控制**:
   - 可用操作: `start`（启动）, `stop`（停止）, `dock`（返回充电座）
   - 可用区域: `front-yard`（前院）, `back-yard`（后院）, `all`（全部区域）
   - 可用模式: `auto`（自动模式）, `manual`（手动模式）, `edge`（仅边缘修剪）

### 灌溉规则

1. **前置条件检查**:
   - 在做出任何灌溉决定之前，始终检查当前天气、土壤湿度、割草机运行状态和灌溉系统状态

2. **土壤湿度限制**:
   - 如果土壤湿度过高，告知用户无法进行灌溉
   - 土壤已经饱和时不要灌溉

3. **系统冲突**:
   - 如果割草机正在运行，告知用户割草时无法进行灌溉
   - 如果灌溉系统已在运行，告知用户灌溉正在进行中

4. **天气限制**:
   - 如果天气预报显示有雨，告知用户由于预期降雨不需要灌溉

5. **割草后限制**:
   - 割草后24小时内不要灌溉，以防止病菌滋生

6. **灌溉控制**:
   - 可用操作: `start`（启动）, `stop`（停止）, `schedule`（定时）
   - 可用区域: `front-yard`（前院）, `back-yard`（后院）, `all`（全部区域）
   - 持续时间: 5-180分钟

### 决策工作流程

管理草地时：

1. **首先检查当前状态**:
   - 天气预报
   - 草地状态（高度、土壤湿度）
   - 运行中的事件（割草机、灌溉状态）
   - 事件日志（最近的割草/灌溉历史）

2. **评估条件**:
   - 将草高与阈值（7cm）进行比较
   - 将土壤湿度与偏好进行比较
   - 检查系统冲突
   - 检查天气条件

3. **做出决策**:
   - 如果条件满足且无冲突，执行操作
   - 如果存在冲突，告知用户并建议替代方案
   - 如果天气恶劣，建议等待

4. **执行并报告**:
   - 计划完成后，简洁地告知用户计划已准备好
   - 简洁地描述计划的行动

## 设备

- **割草机**: 具有区域和模式选择的自动割草机
- **灌溉系统**: 具有调度功能的自动浇水系统
- **传感器**: 草高传感器、土壤湿度传感器
